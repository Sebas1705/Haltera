# ADR NNNN: title as a decision

- **Status:** proposed | accepted | superseded by ADR NNNN
- **Date:** YYYY-MM-DD (from git history)
- **Area:** modules, files or docs the decision touches

## Context

What forces led to the decision. Facts found in the repository only; say "not recorded" when the reason is unknown.

## Decision

What was decided, in the present tense.

## Consequences

What follows from it: benefits, costs, constraints, and how it is checked (tests, CI, scripts).
